# Bundled themes

`celadon.json` (dark) and `celadon-sky.json` (light) are Celadon's own Wiffletree port, copied
unedited from [celadon-theme/celadon-theme](https://github.com/celadon-theme/celadon-theme)
`ports/wiffletree/` at commit `0973b9407169487ea708bccd17f253f1ce1a8a73`. Wiffletree compiles them
in as built-in themes beside Tidal. To update them, copy the port's files again; don't edit them
here.
