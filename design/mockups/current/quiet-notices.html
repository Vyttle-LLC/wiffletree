(c) Notices and agent messages that arrive together share one row instead of interrupting it. The heading counts each kind and names each sender once.

  • Folds: every message Wiffletree sends the coordinator itself, today the PR watcher's and PR keeper's notices, review results, kept worktrees, migration notices, publish results and process notices.
  • Stays a full message: what you write, and the coordinator's own replies. Questions for you keep going to the card above the composer and the Inbox, as today.
  • A notice's pill names what happened (merged, rebased, verification…). If a notice says something failed, such as failing checks or a conflict, the row shows it in red as it does for a failed or blocked report.
  • The dashed outline marks what's new and isn't part of the design.
