Design study · compact context

Compacting an agent’s context by hand

Static study for a proposed Compact action on the Context card that the header’s context chip opens. Only a person triggers it, it takes one optional note on what to keep, and it works for Claude agents only. Each frame shows the conversation header above the Context card. Everything outside the Compact action mirrors the app as it is today. Sample data is simulated.

New agent. With no provider session there is nothing to measure or compact. The card keeps today’s line, the header has no chip, as today, and Compact is off until the first turn has run.

  • Only a person can compact, from this card. There is no coordinator tool and agents cannot compact themselves.
  • A compaction is not a turn: it has no reply, does not wake the agent’s coordinator and does not count toward check-ins.
  • “compacts at 967k” is Claude’s own automatic threshold and is unchanged by this proposal.
  • This is a static design study, not the GPUI implementation. Token figures, model names and ledger numbers are sample data.
