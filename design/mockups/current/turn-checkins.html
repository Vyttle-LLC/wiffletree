Design study · remove turn limits

Where the check-in thresholds are set

Static study for the remove-turn-limits change. Wiffletree has no turn limits. Instead, a parent gets a check-in after a child has run N turns without a message from it, and the human gets an inbox item after the project coordinator has run M turns without them. Each threshold is a row of preset buttons, the same pattern as the round and cycle caps. Choosing one saves at once. Values are simulated.
