Moving a Space's storage

Approved by Michael, November 1, 2026

The change: a Space's storage can move after it is created: from this Mac to GitHub, from GitHub to this Mac, or to another GitHub repository.

Nothing here runs. Vyttle's prefix and issue count are real. The target repository and its readers are samples.

The page reads as any GitHub Space does, with Sync now, and Vyttle's issues, jobs and boards carry on under the same IDs.

  • All or nothing. The files are copied, scanned and pushed first, and the Space switches only after GitHub has them. If a scan holds a file or a push fails, the Space stays where it was and the dialog says why.
  • Nothing is deleted. Old local storage goes to the backups folder, with its Git history. New storage starts with a commit of the current files.
  • Only you can do it. No agent or workspace tool can move storage.
