Files panel — mockup

A new Files button on the right rail. For an agent it shows the files that agent has touched in its ticket's worktree, live. For the coordinator it rolls every agent's files up by ticket. Sample data only.

  • Pulsing dot + highlighted row: a read or write is in progress right now. The strip at the bottom repeats what is live so it stays visible while the tree scrolls.
  • read / edited badges and counts persist for the life of the ticket, so the tree doubles as a record of what the agent looked at.
  • +/− line counts come from the worktree's Git diff against the ticket's base.
  • Yellow tag in the rollup: the same file is being touched by more than one agent or ticket.
  • Touched / Whole tree: default shows only files the agent touched; the toggle shows the full worktree with touched files marked.
