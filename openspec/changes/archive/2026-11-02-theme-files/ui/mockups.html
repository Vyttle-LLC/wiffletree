Theme files

Awaiting approval

A theme is a JSON file in ~/Library/Application Support/Wiffletree/themes/. It changes the app's colors and fonts. You choose one theme for light and one for dark, and Mode decides which is showing: System follows macOS, Light and Dark hold one. Tidal stays built in and is the default for both. These are this Mac's own choices, saved in desktop-preferences.json.

  • A theme can be light, dark or both. A file with only a light variant appears in the Light theme list, one with only a dark variant in the Dark theme list, and one with both, like Tidal, in both lists.
  • Same shape as Tidal. A theme file has a name, its variants with Tidal's 14 color names, and an optional fonts block.
  • A color left out comes from Tidal's same variant. A dark theme can change only the accent.
  • Re-read without a restart. The file is read again when you pick it and whenever a Wiffletree window comes back to the front, so you can edit, switch back and see the change.
  • A broken file never stops the app. Wiffletree draws Tidal's variant instead and shows what is wrong in Settings › Appearance until the file is fixed.

With the choices in section 1

On System, a Mac in light mode shows Celadon Sky; at sunset macOS turns dark and Wiffletree switches to Celadon Jade, fonts included. Light holds Celadon Sky, Dark holds Celadon Jade, whatever macOS does.

A theme recolors everything Tidal colors today: backgrounds, panels, text, borders, the accent button, the focus ring, status colors and the widgets' colors. Fonts change the UI text, code and transcripts, and the base size scales the text that is sized relative to it. The fonts that show are the fonts of the theme on show, so a light and a dark theme with different fonts switch fonts too. These previews do not change with the page's mode; each shows one variant.

3 · Theme files
celadon-jade.json · dark only, as the Celadon port would ship it
{
  "version": 1,
  "name": "Celadon Jade",
  "fonts": {
    "ui": "Figtree",
    "mono": "JetBrains Mono",
    "size": 14
  },
  "variants": {
    "dark": {
      "base": "#060d05", "surface": "#0b150a", "overlay": "#182315",
      "text": "#dbe7d8", "subtle": "#9ba799", "edge": "#748072",
      "accent": "#ffaee7", "on-accent": "#060d05", "focus": "#4ce7d8",
      "green": "#acde83", "red": "#ffb7b0", "yellow": "#ebca60",
      "blue": "#99d4ff", "magenta": "#ffaee7"
    }
  }
}
celadon-sky.json · light only
{
  "version": 1,
  "name": "Celadon Sky",
  "fonts": { "ui": "Figtree", "mono": "JetBrains Mono", "size": 14 },
  "variants": {
    "light": {
      "base": "#eaf6e8", "surface": "#deedda", "overlay": "#cee1ca",
      "text": "#3b423a", "subtle": "#5d675b", "edge": "#7a8378",
      "accent": "#874576", "on-accent": "#eaf6e8", "focus": "#1c7472",
      "green": "#40783b", "red": "#9b4a43", "yellow": "#9c7220",
      "blue": "#246099", "magenta": "#874576"
    }
  }
}
rust-accent.json · partial: Tidal dark with a brighter accent
{
  "version": 1,
  "name": "Tidal, rust accent",
  "variants": {
    "dark": { "accent": "#FF7A59" }
  }
}
  • Variants: light, dark or both. A file with neither is an error. A file with both is Tidal's shape, so Tidal's own file is a valid theme as it stands.
  • Colors are #RRGGBB, with Tidal's names. A color a variant leaves out comes from Tidal's same variant.
  • Fonts name any font installed on this Mac. size is the base text size in points, from 11 to 20; Tidal's is 14. A font or a fonts block left out is Tidal's: the system fonts at 14.
  • Unknown keys, such as Tidal's brand, muted and cyan, are ignored.
  • Celadon's four variants ship as four files, one per variant: celadon-sky is light, and celadon, celadon-powder and celadon-jade are dark.
