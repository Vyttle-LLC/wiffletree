The rule stays in view, because it decides what every project in Vyttle can reach; × stops it and keeps the repositories. A toast names each repository that joins. The page shows six rows and a link to the rest, which opens the dialog, so 25 rows do not push Sources off the screen.

  • What Follow does. When a root check first finds a repository in the folder, Wiffletree adds its owner/name to the Space, as if you had ticked it. The Space's list stays the one record, so a joined repository shows up and comes out like any other.
  • Several roots. A Space can follow any number of root folders, each with its own line, and two Spaces can follow the same one.
  • What stays out. Follow acts only on a first find, so a repository you remove from the Space does not come back. Root checks already skip hidden folders, linked worktrees and repositories with no commit, and one not on GitHub cannot be in a Space.
  • Where it lives. The rule is kept on this Mac, because a path means nothing on another one. In a Space shared with teammates, the repositories it adds still reach them, and their Macs follow nothing unless they turn it on. Removing the root on the Repositories page ends the rule.
  • Several Spaces stay allowed. Ticking a repository for Vyttle leaves it in Personal. Personal lists 21 of these 25 today, so opening its dialog and unticking ~/dev/vyttle clears them in one click.
