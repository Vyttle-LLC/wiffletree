Drive Wiffletree on another computer

One Mac is the host: it runs the agents and keeps the repositories, worktrees, Claude and Codex sign-ins, and the database. Any other Mac you pair, and later an iPhone, opens that host's projects and works in them as if they were local. Nothing about tickets, agents or reviews changes. Only where you are sitting changes.

Control means the device can start and message agents here. Agents run with permission prompts off, so that is the same as running commands on this Mac. Remove takes effect at once, even if the device is offline.

Pairing happens on the host, in person. Someone at Studio Mac turns pairing on and reads the code out, as with Termic. The code is used once to agree on a lasting key for that device, so it is safe even though it is only 4 digits. Wrong guesses close pairing mode.

Shared through a settings repository

Only if both Macs name the same one. Work Studio names sage/wiffletree-settings, your MacBook names you/wiffletree-settings, so their skills and reviews stay separate.

A setting belongs to the Mac whose agents it runs. When the switcher is on Work Studio, the Workspace section, Models, Skills, Repositories, and the usage bars are all Work Studio's: its table, its Claude and Codex accounts, its GitHub sign-in. Switch back to This Mac and you see your personal setup. Nothing about the device you are sitting at changes the host's settings except what you deliberately save there. Only appearance and your list of paired computers belong to the device in front of you.

How it behaves

  • One host per project. A project lives on the Mac that created it. Other devices drive it; they never hold a copy of its database.
  • Credentials stay on the host. Claude, Codex, GitHub and Git credentials are never sent to the device driving it. Publishing and its checks run on the host as they do today.
  • Encrypted, and only paired devices. Every connection is encrypted and checked against the key from pairing. The host listens only while "Let other devices use this Mac's Wiffletree" is on.
  • Same network first, then outside it. The first version is tested on one network. Tailscale or another VPN works by typing the host's name. A relay service for reaching it with neither is not planned.
  • This Mac stays a host too. Your local projects keep working while you drive another Mac.

Decisions this study asks you to confirm

  • New devices start with Control. View only is the alternative, with Control granted afterwards.
  • Quitting asks each time, defaulting to Keep them running. The alternative is a setting with no prompt.
  • Where pairing lives: Settings › Remote access, plus the switcher's Connect a computer.
  • Host settings from another device: a Control device can change the host's settings (Models, Repositories, Skills…). View only devices can read them. Remote access itself changes only at the host.
