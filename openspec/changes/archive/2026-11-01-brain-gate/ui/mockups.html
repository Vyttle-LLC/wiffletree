Each brain's card gains a Gate line: the release its caller pins, the short commit, and whether it is the latest. “Latest” means the newest release this copy of Wiffletree ships, so a Wiffletree upgrade is what makes Update gate appear; nothing is fetched from GitHub to find releases. Update gate appears only when a newer release exists. What changed opens the gate README's release notes on GitHub. A current brain shows no button.

Update gate is a batch like any other. It changes the seven uses: pins in the caller and gate.version in wiffletree-brain.json, nothing else, and its checks run on the new pin. Because CODEOWNERS covers both files, its last step is the code owner's review instead of auto-merge. Log batches keep flowing meanwhile. The card's Gate line moves to v1.1.0 once main holds the merge.

A mismatch holds only that brain's log batches, before any PR opens, so nothing fails on GitHub. Entries are kept on this Mac, not dropped. Compile runs and config PRs, Update gate included, still go through. Contract versions follow the gate's major version: a v1.x gate accepts contract v1. The Brains row in the sidebar counts brains with held logs. Once the update PR merges, the held batch opens on the next pass.

Someone edited the caller by hand, or pinned a commit from a newer Wiffletree. The card says so and offers to pin the latest known release. Logs are not held: the host can't tell which contract that commit accepts, and the gate on GitHub stays the judge.

Choices Michael approved
  • Latest: the newest release this Wiffletree ships (shown here), or the newest on Wiffletree's main fetched from GitHub? Shipping it keeps the writer and the pinned gate in step.
  • Unknown pin: leave logs flowing (shown), or hold them like a mismatch?
  • Sidebar count: count brains with held logs only (shown), or also brains with an update available?

How it behaves

  • The Gate line reads the caller's pin from main and names it by release. gate.version in wiffletree-brain.json is shown only when it disagrees with the pin.
  • Update gate opens one PR through the brain's batch flow, changing only the seven pins and gate.version. It waits for the code owner and never auto-merges.
  • When this Wiffletree's entry contract is newer than the brain's pinned gate accepts, that brain's log batches are held on this Mac until the update merges.
